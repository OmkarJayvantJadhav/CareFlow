# Matplotlib

## 30-second answer
Matplotlib is Python's foundational plotting library: a **Figure** contains one or more **Axes** (plots), and you draw lines, bars, images and text on them, then save as PNG/SVG/PDF. In MedVision AI I used it to generate the evaluation figures that ship in the docs and model card: **training-history curves** (loss and accuracy per epoch), the **confusion matrix**, and **reliability diagrams before and after temperature scaling**. It runs headless with the **`Agg` backend**, so figures are produced in scripts, CI and on Kaggle without a display — and a test checks that backend is used.

---

## Basics you must know

### Two interfaces
```python
import matplotlib.pyplot as plt

# 1. pyplot state machine (quick)
plt.plot(x, y); plt.title("Loss"); plt.show()

# 2. Object-oriented (recommended for code)
fig, ax = plt.subplots(1, 2, figsize=(11, 4))
ax[0].plot(epochs, loss, label="train")
ax[0].set_title("Loss"); ax[0].set_xlabel("Epoch"); ax[0].legend(); ax[0].grid(alpha=0.3)
fig.tight_layout()
fig.savefig("history.png", dpi=150)
plt.close(fig)        # free memory in loops/scripts
```

### Common plot types
| Plot | Function | Use |
|---|---|---|
| Line | `ax.plot` | Training curves |
| Scatter | `ax.scatter` | Relationships |
| Bar | `ax.bar`, `ax.barh` | Per-class metrics |
| Histogram | `ax.hist` | Distributions (e.g. OOD distances) |
| Image / heatmap | `ax.imshow` + `fig.colorbar` | Confusion matrices, Grad-CAM overlays |
| Box plot | `ax.boxplot` | Spread by group |

### Backends
- Interactive: `TkAgg`, `QtAgg`, notebook inline.
- Non-interactive: **`Agg`** (PNG raster) — use in servers, CI, scripts. Set with `matplotlib.use("Agg")` **before** importing `pyplot`.

### Styling essentials
`figsize`, `dpi`, `cmap` (colour map, e.g. `"Blues"`, `"viridis"`), `vmin`/`vmax`, `ax.text` for annotations, `ax.set_xticks/labels(rotation=45)`, `ax.axhline`, `ax.fill_between` (ranges).

## How I used it in MedVision AI (`ml/src/medvision_ml/evaluation/plots.py`)

```python
import matplotlib
matplotlib.use("Agg")                  # headless: Kaggle, CI, scripts
import matplotlib.pyplot as plt

def _save(figure, path):
    path.parent.mkdir(parents=True, exist_ok=True)
    figure.tight_layout()
    figure.savefig(path, dpi=150)
    plt.close(figure)                  # avoid memory growth when many figures are made
    return path
```

| Function | What it draws | Where it appears |
|---|---|---|
| `plot_training_history` | 1×2 subplots: loss and accuracy, train vs validation, per epoch | `outputs/runs/<run>/history.png` after every training run |
| `plot_confusion_matrix` | 8×8 test confusion matrix as an image with class labels | README → `docs/assets/confusion_matrix_test.png` |
| `plot_reliability_diagram` | Accuracy vs confidence per bin with the diagonal and the ECE value | `docs/assets/reliability_test_before.png` and `..._after.png` |

- The reliability diagrams are the visual proof that temperature scaling worked (ECE → 0.026).
- **`ml/tests/test_matplotlib_backend.py`** guards that `Agg` is used — otherwise plotting on a headless machine (Kaggle background run, CI) can fail.
- All figures are regenerated by `make evaluate`, so README numbers and images always come from a real run.

### Note on Grad-CAM images
The served heatmaps are **not** drawn with Matplotlib — the backend colours them with its own NumPy "jet" colour map and encodes PNGs with Pillow, so the server has no Matplotlib dependency. Matplotlib is used only on the training/evaluation side (and the TensorFlow Grad-CAM reference module imports it for figures).

## Interview questions

**Q: Figure vs Axes?**
A Figure is the whole canvas; Axes is one plot inside it with its own x/y axes. `plt.subplots` returns both.

**Q: Why `matplotlib.use("Agg")`?**
To render without a display (servers, CI, background notebook runs). It must be set before importing `pyplot`.

**Q: Why close figures?**
Matplotlib keeps figures in memory until closed; in scripts that make many plots this leaks memory and triggers warnings.

**Q: How do you read a reliability diagram?**
X = predicted confidence per bin, Y = actual accuracy; points under the diagonal mean over-confidence. After temperature scaling MedVision's points lie close to the diagonal.

**Q: How do you plot a confusion matrix?**
`ax.imshow(cm, cmap="Blues")`, set tick labels to class names, annotate counts with `ax.text`, add a colour bar.
