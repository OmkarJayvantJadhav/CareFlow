# JavaScript

## 30-second answer
JavaScript is the language of the browser (and, with Node.js, of servers and build tools). It is dynamically typed, single-threaded with an event loop, and uses promises / `async`–`await` for asynchronous work. I wrote both project frontends in **plain JavaScript (no TypeScript) with React**: CareFlow's patient, front-desk, doctor and admin screens, and MedVision's single-card analysis UI. In MedVision I kept the API "typed" without TypeScript by testing frontend fixtures against the backend's OpenAPI schema.

---

## Basics you must know

### Variables and types
- `const` (cannot be re-assigned), `let` (block-scoped), avoid `var` (function-scoped, hoisted).
- Primitive types: `string`, `number`, `boolean`, `null`, `undefined`, `bigint`, `symbol`. Everything else is an object (arrays and functions too).
- `===` compares without type conversion; prefer it over `==`.
- Truthy/falsy: `0`, `""`, `null`, `undefined`, `NaN`, `false` are falsy.

### Functions and scope
- Arrow functions `(a) => a * 2` do not have their own `this`.
- **Closures:** an inner function remembers variables of the outer function. CareFlow's `api.js` keeps `token` in module scope and every `api()` call reads it.
- Higher-order array methods: `map`, `filter`, `reduce`, `find`, `some`, `every`.

### Modern syntax
- Destructuring: `const { status, reasons } = result;`
- Spread: `{ ...base, ...reply }` (used in CareFlow's chat tests to build mocked replies).
- Optional chaining and nullish coalescing: `body?.error?.code ?? "http_error"` (MedVision `client.js`).
- Template literals: `` `/api/v1${path}` ``.
- ES modules: `import` / `export` (`"type": "module"` in `package.json`).

### Asynchronous JavaScript
- **Event loop:** one thread; long work is split into callbacks. Microtasks (promise callbacks) run before macrotasks (timers, I/O).
- **Promise:** a value that will be available later — pending → fulfilled / rejected.
- **async/await:** syntax over promises; use `try/catch` for errors.
- **fetch:** `await fetch(url, { method, headers, body })`, then `await response.json()`. `fetch` only rejects on network failure, so you must check `response.ok` yourself.
- **AbortController:** cancel an in-flight request (MedVision passes a `signal` so an old analysis is cancelled when a new image is dropped).

### Browser APIs I used
- `WebSocket` (CareFlow live queue), `FormData` (MedVision image upload), `window.setInterval` (polling fallback), clipboard paste (MedVision accepts Ctrl+V of an image), `localStorage`-style preferences (theme).

## How I used it

### CareFlow — `ui/src/api.js`
A thin wrapper around `fetch` that adds the bearer token and turns server errors into an `ApiError` with a stable `code`, so screens can show a friendly message in the user's language:
```js
export async function api(path, options = {}) {
  const headers = { Accept: "application/json" };
  if (options.body !== undefined) headers["Content-Type"] = "application/json";
  if (token) headers.Authorization = `Bearer ${token}`;
  const response = await fetch(`/api/v1${path}`, { method: options.method ?? "GET", headers,
    body: options.body === undefined ? undefined : JSON.stringify(options.body) });
  const data = await response.json().catch(() => ({}));
  if (!response.ok) { /* 401 → sign out; throw ApiError(code, message, status) */ }
  return data;
}
```
`socketUrl(sessionId)` builds `ws://` or `wss://` depending on whether the page is on HTTPS.

**Live queue with fallback** (`ui/src/pages/QueueStatus.jsx`): open a `WebSocket`; on every message re-fetch the queue; on `onerror`/`onclose`, start polling every 5 seconds; clear everything in the `useEffect` cleanup.

**i18n** (`ui/src/i18n.js`): every visible string in English, Hindi and Marathi.

### MedVision — `frontend/src/api/client.js`
- `explain(file)` builds a `FormData`, posts to `/api/v1/explain`, and returns prediction + base64 heatmap PNGs in one call.
- Every failure becomes `ApiError(code, message, status)`; network failures become `network_error`.
- **Contract test without TypeScript** (`frontend/src/api/contract.test.js`): test fixtures are checked against `openapi.json` generated by the backend — every required field must exist and no unknown field may appear. A backend test fails if `openapi.json` is stale.

### Tooling
- ESLint (both), Prettier (MedVision), Vitest (both), Vite (both).

## Interview questions

**Q: `let` vs `const` vs `var`?**
`const` and `let` are block-scoped; `const` cannot be re-assigned (objects can still be mutated). `var` is function-scoped and hoisted, which causes bugs.

**Q: Explain the event loop.**
JS runs on one thread. The call stack runs synchronous code; finished async work queues callbacks. When the stack is empty, the loop runs all microtasks (promise reactions), then one macrotask (timer, I/O), and repeats.

**Q: Why choose plain JavaScript instead of TypeScript?**
To keep the frontends small and simple. I protected the API contract another way: MedVision's tests validate mock data against the backend's OpenAPI schema, so a renamed field breaks a test just like a type error would.

**Q: Does `fetch` throw on HTTP 500?**
No. It only rejects on network errors. You must check `response.ok` — both my API clients do and throw a typed `ApiError`.

**Q: What is a closure? Example?**
A function plus the variables it captured. In CareFlow's `QueueStatus` effect, `startPolling` and `ws.onclose` close over the local `poll` and `closed` variables so cleanup can stop the right timer.

**Q: How do you avoid memory leaks with WebSockets/timers in React?**
Return a cleanup function from `useEffect` that closes the socket and clears intervals — CareFlow does exactly that.

## Cheat sheet
- `arr.map(fn)`, `arr.filter(fn)`, `arr.reduce((acc, x) => acc + x, 0)`
- `Object.keys/values/entries`, `JSON.stringify/parse`
- `await Promise.all([a(), b()])` — run in parallel
- `structuredClone(obj)` — deep copy
- `encodeURIComponent(token)` — used when putting the token in the WebSocket URL
